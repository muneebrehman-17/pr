# Ask Muneeb — Portfolio Assistant

## Overview

Ask Muneeb is a lightweight interactive portfolio assistant designed to guide visitors through the portfolio experience in a smooth, modern, and conversational way.

The assistant should feel:
- Friendly
- Smart
- Modern
- Developer-oriented
- Helpful but minimal

This is NOT a full AI chatbot.

The purpose is:
- portfolio navigation
- answering common client questions
- showcasing projects
- improving interaction quality
- increasing freelance conversions

The assistant should never feel overwhelming or distracting.

---

# Personality

Tone:
- Friendly developer
- Professional but relaxed
- Confident without sounding corporate
- Conversational and clean

Communication Style:
- Medium length responses
- Human-like
- Clear and direct
- Minimal fluff

Introduction Style:
"Muneeb is a full stack developer focused on architecture, scalable web applications, landing pages, and modern digital experiences."

---

# Primary Goal

The assistant should help freelance clients quickly understand:
- who Muneeb is
- what services are offered
- technical expertise
- featured projects
- how to contact him

The assistant should guide users naturally toward:
- viewing projects
- starting a conversation
- freelance inquiries

---

# Assistant Name

Ask Muneeb

---

# Opening State

The assistant should NOT auto open.

Default state:
- Floating rounded button
- Bottom right corner
- Soft glassmorphism
- Subtle hover glow
- Smooth floating animation

Button Label:
"Ask Muneeb"

---

# Opening Animation

When opened:
- Fade in
- Scale from 0.96 → 1
- Duration: 0.35s
- Smooth spring easing

Avoid:
- Bounce animations
- Fast popups
- Aggressive motion

---

# Initial Message

"Hey, I’m Muneeb’s portfolio assistant. What would you like to explore?"

---

# Suggested Questions

Display predefined prompt chips immediately.

## Primary Questions

- Who are you?
- Show projects
- Tech stack

---

# Question Behavior

Questions should:
- instantly respond
- feel smooth
- avoid long fake typing delays
- optionally show a small typing indicator for 400–700ms

---

# Response Style

Responses should:
- stay concise
- feel natural
- avoid robotic formatting
- avoid large paragraphs

Good:
2–5 lines maximum.

---

# Smart Interaction Rules

After every response:
- show 2–3 related follow-up suggestions

Example:
After "Tech stack"

Suggestions:
- Show projects
- Freelance availability
- Contact Muneeb

---

# Portfolio Integration

The assistant should interact with the website itself.

Examples:
- "Show projects" → smooth scroll to projects section
- "Tech stack" → highlight skills section
- "Contact" → scroll to contact section

Scrolling should:
- use smooth easing
- feel cinematic
- never snap instantly

# Do Rules

- Keep interactions clean and smooth
- Focus on helpful navigation
- Keep answers conversational
- Prioritize project visibility
- Maintain premium visual quality
- Use subtle animations only
- Keep interactions fast
- Make scrolling feel smooth
- Maintain modern developer aesthetic
- Keep interface minimal
- Use elegant motion easing
- Encourage exploration naturally

---

# Don’t Rules

- Do NOT behave like ChatGPT
- Do NOT generate massive responses
- Do NOT feel robotic
- Do NOT overuse emojis
- Do NOT use excessive animations
- Do NOT auto-open the assistant
- Do NOT interrupt browsing
- Do NOT use fake AI jargon
- Do NOT use neon cyberpunk styling
- Do NOT use typing delays longer than 1 second
- Do NOT cover important page content
- Do NOT ask too many questions
- Do NOT feel like customer support software
- Do NOT make the UI look playful or childish
- Do NOT overcomplicate interactions

---

- an elegant portfolio layer

- a modern interactive guide

NOT:
- a support chatbot
- an AI gimmick
- a generic widget
